# 0.3.0-rc.6 — потоковая проверка XML

Полная проверка XML больше не строит дерево там, где нужны только корневые

связь с CF и корректность XML. Ранняя проверка основной и конечное чтение всех
файлов сохранены. Новый dependency не нужен; Rust и формирование XML прежние.

Windows/Linux тесты и настоящие PostgreSQL DB→две XML проверки пройдены.

и пакетирование мелких заданий исследованы, но не включены: дополнительного
убедительного выигрыша после основной оптимизации они не дали.

  представления конфигураций не менялись; известные ограничения XML остаются.

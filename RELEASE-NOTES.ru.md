# 1CDB2SRC 0.2.0 — 21.10.2026

В Docker и Linux native включён новый конвертер и обновлены Python helpers.
Единая точка входа — Python; CF→XML выполняет включённый ibcmd-rs на Rust.
Платформа 1С при извлечении не используется.

- Поддержаны старые корни 67/60 и 68/61 с независимыми координатами совместимости.
- Исправлена выгрузка нескольких назначений приложения и наследуемого TitleFont.
- Явный профиль 8.5.1 может читать поддержанные старые корни; auto сохранён.
- Современная подпись .10 сохраняется с проверкой всех байтов CF и владельца;
  криптографическая достоверность подписи не проверяется, подпись не пересоздаётся.
- Исправлена проверка длинных путей Windows.
- Добавлены переносимые проверки профилей, подписи и целостности результата.

Проверенная основная конфигурация Документооборота: XML2.20, загрузка пользователем
на8.3.27 и сравнение с исходной без отличий. Точная сборка8.3.27 не зафиксирована.
Извлечённые основные XML из MSSQL/PG ранее побайтово совпали; отдельно загрузка
PG не заявляется. При подготовке этого выпуска базы повторно не читались.
Версии XML и выбор `--platform` пояснены в единой README.

Ограничения: загрузка2.20 на8.5 дала массовые различия свойств форм;
поддержка чистого roundtrip8.5 не принята. Сохраняются прежнее различие
UseAlways/plain/~, пустые локализованные подписи одной формы и представление
картинок двух макетов СКД2.21 (PNG встроен, sidecar отсутствует). Закрытый код
не восстанавливается. Полная поддержка произвольных конфигураций не заявлена.

Принятый ELF:65435328байт,
SHA256 `e4823a015f093e3e805da57f874793cf767d35675314baf58a13424f3f67a0df`.
История предыдущего выпуска сохранена ниже.

## Предыдущее обновление прав — 21.10.2026

Исправлен порядок сериализации существующих прав объектов Catalog и
InformationRegister. Права, значения и ограничения доступа не добавляются
и не удаляются. Правило основано на независимых примерах штатной выгрузки;
исключений по именам пользовательской конфигурации нет.

Исправление включено в поставленный Docker-образ и Linux native-конвертер.
SHA256 ELF: `b087962e13423f833ccae5e495423fa2228767da628f3c06a375ba48b7a48358`.
Существующий Python CLI и параметры подключения сохранены.

Проверено: 5 schema-тестов, 6 production-тестов и адресная генерация четырёх
Rights.xml из каждого независимого MS SQL/PostgreSQL CF. Все восемь файлов
совпали с контролем побайтно. Контроль не является входом конвертера.

После упаковки выполнены свежие offline-установки Windows/Linux и обработка
двух сохранённых малых CF: профили → native XML → DumpInfo → вложенные CF →
сборка каталога. Windows Docker — 16,33 с, Linux native — 19,87 с, Linux
Docker Engine — 24,35 с. Все 15 выходных путей и их байты одинаковы между
режимами и прежним малым результатом. Windows: 34 теста PASS/17 Linux-only
пропущены; Linux: 51 PASS. Это не новый сквозной запуск от живой БД и не
повторный полный экспорт большой конфигурации.

Остаётся одно из пяти исследованных различий большой конфигурации:
маркер `~` у поля формы UseAlways и связанная позиция при сортировке.
Правило его нативной сериализации не установлено; код формы не менялся.
Подробнее: [ограничение binding формы](converter/docs/form-binding-scope.md).
Другие ограничения XML, включая версию/совместимость малого стенда и opaque
служебные записи, сохранены. Полное равенство произвольной штатной XML-выгрузке
и загрузка результата платформой не заявляются. Доступный BSL не изменён.

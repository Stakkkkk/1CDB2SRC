# Исторические сведения

Эти JSON — публичные копии исторических результатов. Названия проекта и пути
приведены к нейтральному виду; ссылки между архивными копиями обновлены.
Вложенные хеши исходников относятся к исходным артефактам прежних выпусков,
а не к текущему переименованному коду. Это не новые проверки.
Исходные документы сохраняются в истории Git; история не переписывалась.
Текущая проверка перечислена только в корневом release-validation.json.
